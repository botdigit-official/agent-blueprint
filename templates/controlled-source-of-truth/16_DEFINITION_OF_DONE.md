# 16 — Definition of Done (DoD)

A task or feature is ONLY complete when all criteria are satisfied:

1. **Code Implementation:** Clean, idiomatic, adhering to project conventions.
2. **Automated Verification:** Unit and/or integration tests pass with 0 errors.
3. **Living Docs Synchronized:** Corresponding `docs/` documents updated.
4. **Audit Trail Appended:** `CHANGELOG.md` updated with files touched.
5. **No Regressions:** Existing test suites and builds compile cleanly.
