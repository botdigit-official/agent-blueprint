# Fintech Example

This directory shows how Project Skills OS applies to a fintech project.

## Archetype

A financial system with:
- Accounts, balances, transactions
- Ledgers and reconciliation
- Compliance requirements
- High data integrity requirements
- Audit trails

## Skills Activated

### Always
- 00-orchestrator
- 01-discovery
- 05-documentation

### Conditional
- 03-business-architecture (financial rules, accounting, compliance — mandatory)
- 04-architecture
- 06-codebase-audit
- 07-security (payments, user data, financial transactions — mandatory, highest scrutiny)
- 08-testing (financial logic must be tested rigorously)
- 09-performance

### Stack (detected)
- stacks/[language]
- frameworks/[framework]
- stacks/[database]
- stacks/[infrastructure]

## Minimum Documentation (Tier 4 — Regulated)

Tier 3 plus:
- COMPLIANCE.md
- AUDIT/ (audit reports and trail)
- Data governance documentation
- Disaster recovery documentation
- Extra attention to data integrity, audit trails, and immutable records
