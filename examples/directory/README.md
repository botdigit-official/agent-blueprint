# Directory Example

This directory shows how Project Skills OS applies to a directory or listing platform.

## Archetype

A curated or user-generated listing platform with:
- Categories and search
- Listings with structured data
- User submissions and moderation
- Potentially ratings and reviews

## Skills Activated

### Always
- 00-orchestrator
- 01-discovery
- 05-documentation

### Conditional
- 03-business-architecture (categories, listings, moderation, user submissions)
- 04-architecture
- 06-codebase-audit
- 07-security (if user data is handled)
- 08-testing
- 09-performance (search and listing retrieval are core)

### Stack (detected)
- stacks/[language]
- frameworks/[framework]
- stacks/[database]
- stacks/[search] (if search is a feature)

## Minimum Documentation

Tier 2 or 3 depending on complexity. Directories with user submissions and moderation need the full Tier 3.
